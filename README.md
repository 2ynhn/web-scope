# web-scope
Web browsing utility toolkit

웹 서핑을 도와주는 크롬(Chromium) 확장 프로그램 도구 모음입니다.
팝업에서 기능별로 켜고 끌 수 있고, 톱니바퀴 버튼으로 각 기능의 상세 설정 페이지로 이동합니다.

## 기능

| 기능 | 설명 | 기본 설정 |
| --- | --- | --- |
| **화면 맞춤** | 화면보다 큰 이미지/영상을 화면 세로 크기에 맞춤. 마우스를 올리면 원본/맞춤 전환 버튼 표시 | 화면 높이의 96% |
| **미디어 이동** | 이미지/영상이 여럿 있으면 `PageDown` / `PageUp` 으로 다음·이전 미디어로 스크롤 | 200×200px 이상 3개 이상 |
| **만화 뷰어** | 만화형 이미지를 전체 화면 뷰어로 보고 `←` `→` 로 넘김 | 300×400px 이상 3개 이상 |

### 만화 뷰어

- 가로 300px, 세로 400px 이상 이미지가 3개 이상이면 오른쪽 아래에 **만화보기** 버튼이 나타납니다.
  (팝업의 **지금 열기** 버튼 또는 `Alt+Shift+V` 로도 열 수 있음)
- 현재 화면에 보이는 이미지부터 시작하고, 닫으면 마지막으로 본 이미지 위치로 페이지가 이동합니다.
- **넘김 방향**: 오른쪽 넘김(→ 다음) / 왼쪽 넘김(← 다음). 뷰어 상단 버튼이나 설정 페이지에서 바꾸며, 바꾸기 전까지 유지됩니다.
- 뷰어가 열려 있는 동안에는 사이트의 키보드 단축키가 동작하지 않도록 막습니다.
- **동적 로딩 이미지**: 스크롤해야 나타나는 이미지(지연 로딩, 무한 스크롤)도 계속 불러옵니다.
  뷰어 뒤의 실제 페이지를 스크롤해서 사이트의 로딩을 유도하고, 새로 나타난 이미지는 뷰어 목록에 바로 추가됩니다.
  남은 이미지가 5장 미만이 되면 끝에 닿기 전에 미리 다음 이미지를 불러오고,
  마지막 이미지에서 다음으로 넘기면 최대 6초간 새 이미지를 기다립니다.
  (설정의 "동적 로딩 이미지 불러오기"로 끌 수 있음)

| 키 | 동작 |
| --- | --- |
| `→` / `←` | 다음 / 이전 (넘김 방향에 따라 바뀜) |
| `PageDown` `Space` / `PageUp` `Shift+Space` | 다음 / 이전 |
| `Home` / `End` | 처음 / 마지막 |
| `F` | 풀화면 전환 |
| `Esc` | 만화보기 닫기 (풀화면일 땐 먼저 풀화면 해제) |

화면 좌/우 1/3 클릭으로도 넘길 수 있고, 가운데 클릭은 메뉴 표시 전환, 가운데 더블클릭은 풀화면 전환입니다.

## 설치 (개발자 모드)

1. `chrome://extensions` 열기 → 오른쪽 위 **개발자 모드** 켜기
2. **압축해제된 확장 프로그램을 로드합니다** → 이 저장소 폴더 선택

## 구조

```
manifest.json
background.js            배지(켜진 기능 수), 단축키 처리
common/defaults.js       기능 목록·기본 설정·저장소 헬퍼 (공용)
common/ui.css            팝업/설정 페이지 공용 스타일
content/fit-media.js     1. 화면 맞춤
content/media-nav.js     2. 미디어 이동
content/comic-viewer.js  3. 만화 뷰어
popup/                   기능 on/off 팝업
options/                 기능별 상세 설정 페이지
icons/
```

설정은 `chrome.storage.sync` 에 기능별 키(`fitMedia`, `mediaNav`, `comicViewer`)로 저장됩니다.
